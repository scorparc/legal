# scorparc/legal

Legal notice, privacy policies and the app list for the Android apps by Vardholt.
The apps load the JSON files from this repository (at most once every 24 hours) and
keep a bundled copy for offline use. The HTML versions are served via GitHub Pages.

- Legal notice: https://scorparc.github.io/legal/impressum.html
- Privacy policy of an app: `https://scorparc.github.io/legal/<app>/datenschutz.html`
- Language versions use a suffix, for example `datenschutz_en.html`.
